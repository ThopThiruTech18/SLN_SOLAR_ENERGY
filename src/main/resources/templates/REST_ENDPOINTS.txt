📌 Students: /api/students
   - POST   /           → Create student
   - PUT    /{id}       → Update student
   - GET    /{id}       → Get by ID
   - GET    /           → Get all students
   - GET    /active     → Get active students
   - DELETE /{id}       → Delete student
